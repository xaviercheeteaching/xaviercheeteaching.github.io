Chapter 1: Python Fundamentals for Precision Health#

1. Introduction#

In precision health, you will frequently need to perform the same action on a collection of items, whether it’s processing a list of patient lab results, analyzing a sequence of genetic markers, or checking a batch of sensor readings. This section introduces the for loop, a powerful and fundamental tool that allows you to automate these repetitive tasks. The learning journey will take you from understanding the core components of a loop to applying them in medically relevant scenarios. By the end of this section, you will be able to write a for loop to access and process each item in a sequence.

2. Key Concepts and Definitions#

To effectively use for loops, it’s important to understand the following core terms. These concepts form the building blocks of iteration in Python.

  • Iterable: The sequence or collection that the loop iterates over, such as a list of patient IDs or a collection of blood pressure readings. In a medical analogy, this is the entire rack of patient files to be reviewed.

  • Loop Variable: A temporary variable that holds the value of the current item from the iterable for each pass of the loop. For example, if looping through a list of glucose readings, the loop variable would hold the value of one specific reading at a time.

  • Loop Body: The indented block of code that executes once for each item in the iterable. This is where you define the specific action to be performed, such as printing a value, performing a calculation, or checking a condition on the current item.

3. Main Content#

A for loop provides a clean and efficient way to iterate over the items of a sequence. The basic structure is for [variable] in [iterable]:, where the indented code block below it is executed for each item.

Let’s break down a practical example using a list of blood glucose readings. Based on clinical best practices, we specify that these are post-meal readings to provide accurate context for any analysis.

# A list of 2-hour post-meal blood glucose readings (mg/dL).
glucose_levels = [99, 145, 85, 160] # The iterable

for level in glucose_levels: # 'level' is the loop variable
    # The indented code below is the loop body
    print(f"Logged reading: {level} mg/dL")

# Expected Output:
# Logged reading: 99 mg/dL
# Logged reading: 145 mg/dL
# Logged reading: 85 mg/dL
# Logged reading: 160 mg/dL

This loop systematically goes through the glucose_levels list, assigning each value to the level variable one by one and printing it. Once the last item has been processed, the loop concludes.

Calculate Average Heart Rate Intermediate

Objective: Use a for loop to calculate the average value of a list of numbers. Time: 7 minutes Medical Context: Calculating averages from time-series data is a common task, such as finding a patient’s average heart rate over a monitoring period to assess their cardiovascular stability.

Given a list of hourly heart rate measurements (beats per minute), calculate and print the average heart rate.

heart_rates_bpm = [72, 75, 68, 71, 78, 80, 74]

Solution

heart_rates_bpm = [72, 75, 68, 71, 78, 80, 74]
total_hr = 0

for rate in heart_rates_bpm:
    total_hr += rate # Add the current rate to the total

# It's safer to check for an empty list to avoid a ZeroDivisionError
if len(heart_rates_bpm) > 0:
    average_hr = total_hr / len(heart_rates_bpm)
    print(f"Average Heart Rate: {average_hr:.2f} bpm")
else:
    print("No heart rate data to average.")

Explanation: We initialize total_hr to zero. Inside the loop, each rate is added to total_hr. After the loop, the average is calculated by dividing the total sum by the number of items in the list, obtained using len(). Key Learning: Using a loop to aggregate data from a list, a pattern known as an “accumulator.”

Solution

medication_list = ["Levo-thyroxine", "Meta-prolol", "Lisinopril", "Levo-cetirizine"]
thyroid_meds = []
cardiac_meds = []

for med in medication_list:
    if med.startswith("Levo-"):
        thyroid_meds.append(med)
    elif med.startswith("Meta-"):
        cardiac_meds.append(med)

print(f"Thyroid Meds: {thyroid_meds}")
print(f"Cardiac Meds: {cardiac_meds}")

Explanation: The loop iterates through each med string. The startswith() string method is used to check the prefix of each medication. Based on the result, the append() method adds the medication name to the appropriate category list. Key Learning: Using string methods and conditional logic within a for loop to sort and categorize data.

5. Practical Applications#

For loops are indispensable in precision health for automating repetitive data processing tasks. Each application uses the for loop programming technique to achieve a significant real-world impact.

  • Automated Lab Result Analysis: At medical centers, laboratory information systems (LIS) use for loops to automatically process thousands of test results daily. The loop iterates through batches of results, flags abnormal values for clinician review, and routes them to the correct electronic health record (EHR), ensuring timely patient care.

  • Batch Processing Genomic Data: A bioinformatician might write a for loop to iterate through a list of thousands of gene sequence files. The loop body would contain code to open each file, run an analysis (e.g., search for a specific mutation), and save the result, automating a process that would be impossible to do manually and accelerating genetic research.

  • Data Validation in EHRs: When importing a new set of patient records, a data scientist can use a for loop to iterate through each record. Inside the loop, they can run checks to ensure data integrity, such as verifying that every patient has a valid ID or that all lab values fall within a plausible range, improving data quality for clinical analytics.

6. Summary and Key Takeaways#

In this section, we’ve explored the for loop, a cornerstone of programming for automation and data processing. We learned how to construct a loop to iterate over a sequence, use the loop variable to access each item, and execute a block of code for every item.

  • for loops are essential for automating repetitive tasks on sequences of data.

  • The key components of a loop are the iterable (the sequence), the loop variable (the current item), and the loop body (the code to execute).

  • By combining loops with conditional statements (if), you can perform powerful, selective actions on your data.

  • Loops are frequently used in precision health for everything from data validation and analysis to report generation.

This foundational understanding of loops is a critical step. As a final thought, besides flagging high values, what other automated checks could a for loop perform on a list of patient lab results? Consider checking for critically low values or calculating the average of the readings. Next, we will explore how to gain more control over our loops using functions like range() and other advanced iteration techniques.
