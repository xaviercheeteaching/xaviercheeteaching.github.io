Chapter 1: Python Fundamentals for Precision Health#

1. Introduction#

Welcome to the next level of loop mastery. While for loops are excellent for processing every item in a sequence, real-world scenarios often require more nuanced control. In this section, you will learn how to use the break, continue, and for...else statements to precisely manage loop execution. This is essential for writing efficient code, such as searching patient data for a single critical flag and stopping immediately, filtering out irrelevant records from a large dataset, or confirming the absence of a contraindication before administering treatment. By the end of this lesson, you will be able to build more responsive and intelligent loops for your precision health applications.

2. Key Concepts and Definitions#

Understanding these control statements is key to writing efficient and readable loops.

  • Loop Control Statement: A command that alters the normal execution flow of a loop. In a clinical system, these are used to react to specific data points, like stopping a search for a genetic marker once it’s found or skipping over records that don’t need processing.

  • break: This statement immediately terminates the innermost loop it is in. Think of it as a clinical “stat” order that stops all other processing to focus on a critical finding, such as halting a review of patient vitals once a value crosses a life-threatening threshold.

  • continue: This statement skips the rest of the code inside the current iteration of a loop and proceeds to the next iteration. This is useful for filtering data, similar to a lab technician skipping over stable samples to focus only on those that are flagged for further analysis.

  • for...else Clause: The else block attached to a for loop executes only when the loop has completed all its iterations naturally, without being terminated by a break statement. This is a powerful way to confirm a condition’s absence, such as verifying that a patient has no recorded allergies to a prescribed medication.

3. Main Content#

Let’s explore how to use break, continue, and the for...else clause to write more sophisticated and efficient loops.

3.1 The break Statement: Exiting a Loop Early#

The break statement provides a way to exit a loop immediately. This is highly efficient for “search” operations where you only need to find the first occurrence of a condition.

Use Case: Find the first heart rate indicating tachycardia in a log. Once found, flag it and stop checking the rest of the log.

# In a real application, thresholds are often configured as constants.
ALERT_THRESHOLD = 100
heart_rate_log = [72, 75, 81, 105, 88, 92]

for heart_rate in heart_rate_log:
    if heart_rate > ALERT_THRESHOLD:
        print(f"Heart rate {heart_rate} bpm exceeds threshold. Flagging for review.")
        break
    print(f"Heart rate stable: {heart_rate} bpm.")

In Practice: In time-critical situations, such as monitoring a patient for sepsis or a cardiac event, finding the first sign of trouble is paramount. Using break ensures the system can issue an alert immediately without wasting precious seconds or milliseconds processing non-critical data that follows.

3.2 The continue Statement: Skipping an Iteration#

The continue statement allows you to skip the remainder of the current iteration and move directly to the next one. It is ideal for filtering out items you don’t need to process.

Use Case: Process only core lab panels, such as a CBC (Complete Blood Count) or BMP (Basic Metabolic Panel), from a list of test orders.

lab_orders = ["CBC", "LIPID", "BMP", "TSH"]
core_panels = ["CBC", "BMP"]

for test in lab_orders:
    if test not in core_panels:
        continue  # Skip non-core tests
    print(f"Processing core lab order: {test}")

Pro Tip: The continue statement is a powerful tool for data cleaning and validation. Before performing complex calculations or analysis on a dataset, you can loop through it and use continue to skip over rows with missing values, invalid entries, or data points that fall outside the scope of your current task.

3.3 The else Clause in a For Loop: The “No Break” Clause#

The else clause runs only if the loop completes all its iterations without a break. Think of it as a ‘no break occurred’ block, perfect for confirming an item was not found.

Use Case: Check a patient’s recorded allergies before administering a drug.

patient_allergies = ["Penicillin", "Sulfa", "Ibuprofen"]
DRUG_TO_ADMINISTER = "Aspirin"

for allergy in patient_allergies:
    if allergy == DRUG_TO_ADMINISTER:
        print(f"Allergy found: {allergy}. Do not administer.")
        break
else:
    # Executes only because the loop finished without a 'break'.
    print(f"No allergy to {DRUG_TO_ADMINISTER} found. Proceed with safety protocols.")

Pro Tip: Think of the else on a loop as the “all-clear” signal. It only runs if the loop completed its full patrol (all iterations) without raising an alarm (break). This makes it perfect for confirming that a specific condition was not met in an entire dataset.

Debug Note: A common mistake is confusing a loop’s else clause with a standard if/else statement. Remember, the loop’s else is tied to the break statement, not the if condition. It will not run if the loop is exited via break.

4. Practice Exercises#

Exercise 1: Fever Detection Basic#

Objective: Use break to stop a loop as soon as a critical condition is met. Time: 5 minutes Medical Context: Early fever detection is crucial for timely intervention. This exercise simulates an automated system that scans recent temperature readings and flags the first sign of fever.

Task: Given patient_temperatures_celsius, write a loop that prints “Fever Alert!” and stops immediately when it finds the first temperature greater than or equal to 38.0°C (>= 38.0).

📝 Your Solution:

Solution

patient_temperatures_celsius = [36.6, 37.0, 37.1, 39.2, 37.3]
FEVER_THRESHOLD_CELSIUS = 38.0

for temp in patient_temperatures_celsius:
    if temp >= FEVER_THRESHOLD_CELSIUS:
        print(f"Fever Alert! Temperature: {temp}°C")
        break

Explanation: The loop checks each temperature. When it reaches 39.2, the if condition (39.2 >= 38.0) is met, the alert is printed, and the break statement terminates the loop. The final temperature of 37.3 is never checked. Key Learning: break is ideal for stopping a search the moment a condition is met, making code more efficient.

Exercise 2: Filter Billing Codes Intermediate#

Objective: Use continue to filter a list and process only relevant items. Time: 5 minutes Medical Context: A list of billing codes contains both office visit codes (CPT) and drug codes (HCPCS). For an audit, you need to process only the office visit codes.

Task: A list of billing codes is ['99213', 'J0585', '99214']. Write a loop that processes only office visit codes. Use continue to skip any code that does not start with the character ‘9’. Print only the valid office visit codes.

📝 Your Solution:

# TODO: Write your solution here
# Hint: Check the task description above
🔍 Click to reveal solution

Solution

billing_codes = ['99213', 'J0585', '99214']

for code in billing_codes:
    if not code.startswith('9'):
        continue
    print(f"Processing office visit code: {code}")

Explanation: The loop iterates through the codes. For ‘J0585’, the if condition is true, and continue causes the loop to skip the print statement and move to the next item. The codes starting with ‘9’ are processed normally. Key Learning: continue is effective for filtering out items in a list that do not meet processing criteria.

Exercise 3: Medication Safety Check Advanced#

Objective: Use a for...else loop to confirm that an item is not present in a list. Time: 5 minutes Medical Context: Before prescribing a high-risk medication like Warfarin, a clinician must ensure it is not already on the patient’s active medication list to prevent dangerous interactions. This task simulates that safety check.

Task: A patient’s medication list is ['Lisinopril', 'Metformin']. Write a loop to check if ‘Warfarin’ is on the list. If the loop finishes without finding ‘Warfarin’, use the else clause to print “No Warfarin found in records.”

📝 Your Solution:

Solution

medication_list = ['Lisinopril', 'Metformin']
DRUG_TO_CHECK = 'Warfarin'

for med in medication_list:
    if med == DRUG_TO_CHECK:
        print(f"Warning: {DRUG_TO_CHECK} is already on the medication list.")
        break
else:
    print(f"No {DRUG_TO_CHECK} found in records.")

Explanation: The loop checks ‘Lisinopril’ and ‘Metformin’. Neither matches ‘Warfarin’, so the break statement is never executed. Because the loop completes its full run, the else block is triggered, printing the confirmation message. Key Learning: The for...else structure is a clear and explicit way to handle cases where a loop completes a search without finding the target item.

5. Practical Applications#

  • Real-time Vitals Monitoring: An ICU monitoring system can loop through a patient’s vital signs. Using break, the system can immediately trigger an alarm and halt the routine check the instant any single vital sign crosses a critical threshold, ensuring the most urgent issue is addressed without delay.

  • Genomic Data Filtering: When analyzing a patient’s genomic sequence, researchers might search for a list of specific genetic markers. Using continue, a script can iterate through millions of base pairs, skipping over all non-marker sequences and only processing the ones that are relevant to the study, dramatically improving efficiency.

  • Clinical Trial Eligibility Screening: A program can screen a patient’s electronic health record to determine eligibility for a clinical trial. It can loop through a list of disqualifying conditions (e.g., specific allergies). If the loop completes without finding any disqualifying conditions (break is never called), the else block can run to flag the patient as “Potentially Eligible,” confirming they passed the initial screening.

6. Summary and Key Takeaways#

In this section, we’ve explored how to add sophisticated control to our loops. By learning to use break, continue, and the for...else clause, you can write more efficient, readable, and powerful code for handling complex health data.

  • break is your tool for stopping a loop entirely, perfect for when you’ve found what you’re looking for.

  • continue allows you to skip specific items, making it ideal for filtering data.

  • for...else provides a clean way to confirm that a loop finished its entire course without being interrupted by a break, which is invaluable for verification tasks.

These control statements are fundamental building blocks that you will use frequently as you build more complex applications. In the next section, we will learn how to encapsulate and reuse code by creating functions.
