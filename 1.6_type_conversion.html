Chapter 1: Python Fundamentals for Precision Health#

1. Introduction#

In this section, we’ll master a fundamental skill for any health data analyst: converting data between string, integer, and float types. In precision health, data arrives from diverse sources—lab reports as text files, patient inputs from a web form, or readings from a medical device. This data is often in a string format, which is unsuitable for mathematical calculations. This is a critical first step for preparing raw data for clinical calculations, risk scoring, and other computational tasks.

2. Key Concepts and Definitions#

  • Type Conversion (Type Casting): The process of changing a variable from one data type to another. In a medical setting, this is crucial for converting a patient’s age recorded as text ("68") into a number (68) that can be used in a risk assessment algorithm.

  • String (str): A sequence of characters, such as text or numbers, enclosed in quotes. It is the default type for data read from files or user input fields. For example, a blood glucose reading entered into a patient portal, like "6.1", is initially a string.

  • Integer (int): A whole number without a decimal point. Integers are used for countable data, such as a patient’s age in years, the number of hospital admissions, or a heart rate in beats per minute.

  • Float (float): A number that contains a decimal point. Floats are essential for representing measurements that require precision, such as drug dosages (e.g., 1.5 mg), lab values (e.g., WBC count of 11.5), or a patient’s temperature (e.g., 38.2 °C).

  • ValueError: An error that occurs in Python when an operation or function receives an argument of the correct type but an inappropriate value. A common example is trying to convert a string containing non-numeric characters (e.g., float("11.5 cells/L")) into a number, which halts the program.

3. Main Content#

3.1 String to Number Conversion#

In clinical data analysis, raw data often comes in as text. To perform any mathematical operations, such as calculating averages or comparing against reference ranges, you must first convert these text-based strings into numerical types like integers (int) or floats (float).

# Lab data stored as text strings
age_str = "68"
# WBC count in x10^9 cells/L (mildly elevated; normal range is approx. 4.5-11.0)
wbc_count_str = "11.5" 

print(f"Original type of age: {type(age_str)}")

# Convert strings to numbers for calculation
age_int = int(age_str)
wbc_count_float = float(wbc_count_str)

print(f"Patient age: {age_int}, New type: {type(age_int)}")
print(f"WBC count: {wbc_count_float}, New type: {type(wbc_count_float)}")

3.2 Number to String Conversion#

Conversely, you may need to convert a number back into a string, especially when generating reports, creating filenames, or displaying results within a larger text block. Modern Python uses f-strings, which handle this conversion automatically and are the recommended standard.

report_id = 4581

# An f-string implicitly converts the number to create a report filename
report_filename = f"patient_report_{report_id}.txt"

print(f"Report will be saved as: {report_filename}")

Now that we’ve seen how to convert between types, it’s crucial to understand what happens when the data isn’t perfectly clean.

3.3 Handling Conversion Errors#

Your program will crash with a ValueError if you attempt to convert a string that is not compatible with the target numeric type. Robust code anticipates this by using a try...except block to handle the error gracefully.

invalid_wbc_str = "11.5 cells/L"

try:
    # This conversion will fail
    wbc_value = float(invalid_wbc_str)
    print(f"Successfully converted: {wbc_value}")
except ValueError:
    # The error is caught and a message is printed
    print(f"Error: Could not convert '{invalid_wbc_str}' to a float.")

3.4 The int() Truncation Warning#

Important A critical behavior to understand is that int() truncates (cuts off) the decimal part of a float; it does not round to the nearest whole number. This can have significant implications in a medical context, where precision is paramount.

> lab_value_float = 11.9
> lab_value_int = int(lab_value_float)
> 
> # The output shows the decimal was dropped, not rounded up.
> print(f"Original: {lab_value_float}, Truncated: {lab_value_int}")

4. Practice Exercises#

Exercise 1: Convert and Calculate Glucose Level Basic#

Objective: Practice converting a string to a float and performing a calculation. Time: 5 minutes Medical Context: Blood glucose levels are measured differently worldwide. In many countries, they are in mmol/L, while in the US, they are in mg/dL. Converting between these units is a common task.

A blood glucose level is recorded as the string "6.1" mmol/L. Using the constant MG_DL_CONVERSION_FACTOR = 18.018, write a script that:

  1. Prints the data type of the initial string.

  2. Converts the string "6.1" to a float.

  3. Calculates the value in mg/dL.

  4. Prints the final mg/dL value.

  5. Prints the truncated integer value of the result.

  6. Prints the data type of the final calculated value.

Solution

glucose_mmol_L_str = "6.1"
MG_DL_CONVERSION_FACTOR = 18.018

# 1. Print initial data type
print(type(glucose_mmol_L_str))

# 2. Convert to float
glucose_mmol_L_float = float(glucose_mmol_L_str)

# 3. Calculate mg/dL
glucose_mg_dL = glucose_mmol_L_float * MG_DL_CONVERSION_FACTOR

# 4. Print the final mg/dL value
print(glucose_mg_dL)

# 5. Print the truncated integer value
print(int(glucose_mg_dL))

# 6. Print the final data type
print(type(glucose_mg_dL))

Explanation: The script first converts the string "6.1" to a float to enable multiplication. After calculating the result, int() is used to show how truncation removes the decimal portion. The final type is a float because the calculation involved a float. Key Learning: Converting strings to floats is necessary for arithmetic operations. int() truncates, not rounds.

Exercise 3: Cleaning and Converting Temperature Data Advanced#

Objective: Manipulate a string to remove non-numeric characters before conversion. Time: 8 minutes Medical Context: Data from sensors or logs can be “dirty,” containing units or labels mixed with the values. This data must be cleaned before it can be analyzed.

A patient’s temperature is recorded in a log file as the string "38.5 C". This format will cause a ValueError if you try to convert it directly. Write a script that:

  1. Removes the non-numeric part (" C") from the string.

  2. Converts the cleaned string to a float.

  3. Prints the final float value and its type.

Solution

temp_str_dirty = "38.5 C"

# 1. Remove the non-numeric part
# The .replace() method finds " C" and replaces it with an empty string ""
temp_str_clean = temp_str_dirty.replace(" C", "")

# 2. Convert the cleaned string to a float
temperature_float = float(temp_str_clean)

# 3. Print the final value and its type
print(f"Cleaned temperature value: {temperature_float}")
print(f"Data type: {type(temperature_float)}")

Explanation: We use the string method .replace() to create a new string with the unit " C" removed. This “clean” string can then be safely converted to a float without raising a ValueError. Key Learning: Data cleaning is a common and critical first step before type conversion. String methods can be used to prepare data for analysis.

5. Practical Applications#

  • Processing Electronic Health Record (EHR) Data: Lab results (e.g., cholesterol levels, white blood cell counts) are often stored in databases or transmitted as text. Python scripts use float() and int() to convert these string representations into numbers to check for abnormalities, track changes over time, or provide input for diagnostic models.

  • Parsing Medical Device Output: Wearable sensors and hospital equipment, like continuous glucose monitors or ECG machines, often generate data as a stream of text. A program must parse this stream, convert relevant values like "85" (heart rate) or "5.8" (glucose) into numbers, and then log them or trigger alerts if they fall outside a safe range.

  • Analyzing Patient-Reported Outcomes: When patients fill out digital health surveys or input data into a mobile app (e.g., weight, hours of sleep), the data is captured as strings. Backend systems use type conversion to process this information, for example, by converting a string for weight into a float to calculate BMI or track weight loss progress.

6. Summary and Key Takeaways#

In this section, we’ve explored the critical process of type conversion for handling precision health data. We learned that data from external sources often arrives as strings and must be converted to numeric types (int, float) before any mathematical analysis can occur. We also saw how to convert numbers back to strings for reporting purposes.

Key takeaways include:

  • Use int() to convert strings to whole numbers and float() for numbers with decimals.

  • F-strings (f"") are the modern way to embed numbers within strings, as they handle the conversion automatically.

  • Attempting to convert an incompatible string (e.g., one with text or units) will raise a ValueError.

  • The int() function truncates (cuts off) decimals from floats, it does not round them. Use round() for mathematical rounding.

  • Data cleaning is often a prerequisite for successful type conversion in real-world scenarios.

Next, we will build on this foundation by learning how to handle potential errors like ValueError gracefully using error handling techniques.
