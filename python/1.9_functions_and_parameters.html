Chapter 1: Python Fundamentals for Precision Health#

1. Introduction#

This section introduces one of the most fundamental concepts in programming: functions. In the context of precision health, functions are the building blocks for creating reliable and reusable medical logic. Think of a function as a standardized clinical protocol that you can execute on demand—whether it’s for calculating a patient’s BMI, determining a drug dosage, or converting temperature units. Our learning journey will begin with defining simple functions that return a fixed value. We will then progress to making them more flexible by adding parameters, explore different ways to provide arguments, and finally, learn how to handle invalid inputs gracefully to ensure our clinical applications are both powerful and safe.

2. Key Concepts and Definitions#

  • Function: A named, reusable block of code that performs a specific task. In a medical setting, a function is like a defined protocol for a calculation, such as determining a patient’s Mean Arterial Pressure (MAP) from their blood pressure readings.

  • Parameter: The variable name listed inside a function’s parentheses (e.g., weight_lbs). It acts as a placeholder for the input data the function needs to operate.

  • Argument: The actual value that is passed to a function when it is called (e.g., 154.0). This is the real data, like a specific patient’s weight, that fills the parameter’s placeholder.

  • Return Value: The output that a function sends back after it has completed its task. A function to check for fever might return a boolean (True or False), while a dosage calculator would return a number (a float or integer).

  • Docstring: A string literal at the beginning of a function that explains what it does, its arguments, and what it returns. It is crucial for creating understandable and maintainable code, especially in collaborative clinical research projects.

  • Type Hint: A notation that suggests the expected data type of a variable, parameter, or a function’s return value (e.g., -> float). It helps with code clarity and allows tools to detect potential errors, which is critical for safety.

  • Scope: The region of code where a variable is accessible. A variable created inside a function (local scope) is like a patient’s temporary vital signs used for a single calculation, whereas a universal constant like LBS_TO_KG (global scope) is like a widely accepted medical conversion factor available everywhere.

  • None Type: A special Python value representing the absence of a value or a null result. Its medical analogy is a lab test result coming back as “invalid sample” instead of a faulty number. It signals that a calculation could not be completed as intended, preventing the use of erroneous data.

3. Main Content#

3.1 Returning a Fixed Value from a Function#

The simplest function encapsulates a single piece of logic or a value. We use the return keyword to output this value, allowing the result to be stored in a variable for later use. This ensures consistency across an application.

def get_fever_threshold_c():
    """Returns a common clinical fever threshold in Celsius.

    Returns:
        float: The fever threshold value (38.0).
    """
    return 38.0

# The returned value is stored in the 'fever_threshold' variable.
fever_threshold = get_fever_threshold_c()
print(f"The fever threshold is {fever_threshold}°C.")
# Output:
# The fever threshold is 38.0°C.

3.2 Defining a Function with Parameters#

Parameters make functions flexible, allowing them to operate on different input data for various patients or scenarios.

# A constant accessible throughout the file.
LBS_TO_KG = 0.453592

def convert_lbs_to_kg(weight_lbs: float):
    """Converts a weight from pounds to kilograms.

    Args:
        weight_lbs (float): The weight in pounds.

    Returns:
        float: The converted weight in kilograms, rounded to 2 decimal places.
    """
    weight_kg = weight_lbs * LBS_TO_KG
    return round(weight_kg, 2)

# Here, 154.0 is the 'argument' passed to the 'weight_lbs' parameter.
patient_weight_kg = convert_lbs_to_kg(154.0)
print(f"Patient weight recorded: {patient_weight_kg} kg")
# Output:
# Patient weight recorded: 69.85 kg

3.3 Specifying Different Argument Types#

Python offers default, positional, and keyword arguments to increase a function’s flexibility and readability.

def record_administration(drug: str, dose_mg: float, route: str = "Oral") -> None:
    """Logs the administration of a drug.

    Args:
        drug (str): The name of the drug being administered.
        dose_mg (float): The dosage of the drug in milligrams.
        route (str, optional): The administration route. Defaults to "Oral".
    """
    print(f"Logged: {dose_mg}mg of {drug} administered via {route} route.")

# 1. Positional args are passed by order; default for 'route' is used.
record_administration("Ibuprofen", 200.0)

# 2. Keyword args improve clarity; order does not matter.
record_administration(route="IV", drug="Morphine", dose_mg=10.0)
# Output:
# Logged: 200.0mg of Ibuprofen administered via Oral route.
# Logged: 10.0mg of Morphine administered via IV route.

Our functions are now more flexible, but what happens when they receive bad data? It’s crucial to handle invalid inputs gracefully, especially in a medical context.

3.4 Handling Invalid Inputs with None#

Returning None from a function is a robust way to signal a calculation failure without crashing the program, which is essential for building safe clinical tools.

def calculate_bmi(weight_kg: float, height_m: float) -> float | None:
    """Calculates Body Mass Index (BMI).

    Returns None if height is non-positive, as this is a physiological impossibility.
    Formula source: CDC. About Adult BMI. 2022.

    Args:
        weight_kg (float): Patient's weight in kilograms.
        height_m (float): Patient's height in meters.

    Returns:
        float | None: The calculated BMI rounded to one decimal place, or None if input is invalid.
    """
    if height_m <= 0:
        return None  # Signal invalid input.
    bmi = weight_kg / (height_m ** 2)
    return round(bmi, 1)

# Check if the function returned a valid number before using it.
patient_bmi = calculate_bmi(85, 1.75)
if patient_bmi is not None:
    print(f"Patient's BMI is: {patient_bmi}")
else:
    print("Could not calculate BMI due to invalid height.")
# Output:
# Patient's BMI is: 27.8

4. Practice Exercises#

Exercise 1: Calculate Mean Arterial Pressure (MAP) Intermediate#

Objective: Apply function definition, parameter handling, and conditional logic to implement a common clinical calculation. Time: 10 minutes Medical Context: Mean Arterial Pressure (MAP) represents the average pressure in a patient’s arteries during one cardiac cycle and is a key indicator of organ perfusion. A MAP of at least 60 mmHg is generally required to perfuse vital organs. The validation check sbp < dbp is critical, as systolic pressure (contraction) cannot be lower than diastolic pressure (relaxation) in a living person. Automating this calculation reduces the risk of manual error.

Write a function named calculate_map that calculates a patient’s MAP.

  • The function must accept systolic (sbp) and diastolic (dbp) pressures as integer parameters.

  • It must return the calculated MAP as a float, rounded to one decimal place.

  • It must return None if sbp or dbp are non-physiological (e.g., zero or less, or if sbp is less than dbp).

  • The function’s return type should be hinted as float | None.

  • The formula is: [MAP = \frac{(DBP \times 2) + SBP}{3}]

  • Test your function with a valid call (calculate_map(120, 80)) and an invalid call (calculate_map(110, 120)).

def calculate_map(sbp: int, dbp: int) -> float | None:
    """Calculates Mean Arterial Pressure (MAP).

    Returns None for non-physiological BP values (e.g., <= 0, or sbp < dbp).
    Formula source: Lutfi MF. Mean Arterial Pressure. StatPearls. 2023.

    Args:
        sbp (int): Systolic blood pressure in mmHg.
        dbp (int): Diastolic blood pressure in mmHg.

    Returns:
        float | None: The calculated MAP rounded to one decimal place, or None if inputs are invalid.
    """
    if sbp <= 0 or dbp <= 0 or sbp < dbp:
        return None
    map_value = ((dbp * 2) + sbp) / 3
    return round(map_value, 1)

# Example call for a patient with BP 120/80 mmHg
patient_map = calculate_map(120, 80)
if patient_map is not None:
    print(f"Patient's MAP is: {patient_map} mmHg")
else:
    print("Could not calculate MAP due to invalid BP values.")
# Output:
# Patient's MAP is: 93.3 mmHg

# Example call with invalid data
invalid_map = calculate_map(110, 120)
if invalid_map is not None:
    print(f"Patient's MAP is: {invalid_map} mmHg")
else:
    print("Could not calculate MAP due to invalid BP values.")
# Output:
# Could not calculate MAP due to invalid BP values.

Explanation: The function first validates the inputs to ensure they are physiologically plausible. If the data is invalid, it immediately returns None. Otherwise, it proceeds with the calculation, rounds the result, and returns the final value.

Key Learning: Combining input validation with calculation logic in a single function creates a safe and reusable tool.

Exercise 2: Convert Temperature Units Basic#

Objective: Practice defining a simple function with one parameter and a return value. Time: 5 minutes Medical Context: Patient temperatures are recorded in Celsius in some regions and Fahrenheit in others. A conversion function is essential for standardizing data in international clinical trials or health systems.

Write a function convert_c_to_f that takes a temperature in Celsius and returns the equivalent in Fahrenheit, rounded to one decimal place. The formula is [F = (C \times \frac{9}{5}) + 32].

Solution

def convert_c_to_f(temp_c: float) -> float:
    """Converts a temperature from Celsius to Fahrenheit.

    Args:
        temp_c (float): The temperature in Celsius.

    Returns:
        float: The equivalent temperature in Fahrenheit, rounded to one decimal place.
    """
    temp_f = (temp_c * 9/5) + 32
    return round(temp_f, 1)

# Example call
fever_c = 38.0
fever_f = convert_c_to_f(fever_c)
print(f"{fever_c}°C is equivalent to {fever_f}°F.")
# Output:
# 38.0°C is equivalent to 100.4°F.

Explanation: This function takes a single float argument temp_c, applies the conversion formula, and returns the calculated Fahrenheit temperature.

Key Learning: Even simple, single-purpose functions are powerful for making code more readable and preventing repeated logic.

Exercise 3: Calculate Pediatric Dosage Advanced#

Objective: Use default and keyword arguments to create a flexible dosing function that handles edge cases. Time: 10 minutes Medical Context: Pediatric dosing is often weight-based and highly susceptible to error. Functions can enforce safety checks, such as maximum dose limits, to prevent accidental overdoses.

Write a function calculate_pediatric_dose that takes a patient’s weight_kg (float), a dose_mg_per_kg (float), and an optional max_dose_mg (float) with a default value of 500.

  • The function should calculate the total dose.

  • If the calculated dose exceeds max_dose_mg, the function should return max_dose_mg.

  • The function should return None if the weight or dose-per-kg is zero or less.

from typing import Optional

def calculate_pediatric_dose(weight_kg: float, dose_mg_per_kg: float, max_dose_mg: float = 500.0) -> Optional[float]:
    """Calculates a pediatric dose, enforcing a maximum dose limit.

    Args:
        weight_kg (float): The patient's weight in kilograms.
        dose_mg_per_kg (float): The prescribed dose rate in mg per kg.
        max_dose_mg (float, optional): The maximum allowable dose. Defaults to 500.0.

    Returns:
        Optional[float]: The calculated dose, capped at the max dose, or None if inputs are invalid.
    """
    if weight_kg <= 0 or dose_mg_per_kg <= 0:
        return None
    
    calculated_dose = weight_kg * dose_mg_per_kg
    
    if calculated_dose > max_dose_mg:
        return max_dose_mg
    else:
        return round(calculated_dose, 2)

# Example 1: Standard calculation
dose1 = calculate_pediatric_dose(weight_kg=15.5, dose_mg_per_kg=10)
if dose1 is not None:
    print(f"For a 15.5kg child, the dose is {dose1}mg.")
# Output:
# For a 15.5kg child, the dose is 155.0mg.

# Example 2: Dose exceeds the default max
dose2 = calculate_pediatric_dose(weight_kg=40, dose_mg_per_kg=15)
if dose2 is not None:
    print(f"For a 40kg child, the calculated dose is capped at {dose2}mg.")
# Output:
# For a 40kg child, the calculated dose is capped at 500.0mg.

# Example 3: Using a custom max dose with keyword arguments
dose3 = calculate_pediatric_dose(dose_mg_per_kg=15, weight_kg=40, max_dose_mg=1000.0)
if dose3 is not None:
    print(f"With a higher max dose, the calculated dose is {dose3}mg.")
# Output:
# With a higher max dose, the calculated dose is 600.0mg.

Explanation: The function first validates the inputs. It then calculates the dose and uses an if statement to cap the dose at the max_dose_mg if necessary. The use of a default argument for max_dose_mg makes the function flexible.

Key Learning: Functions can embed clinical safety rules directly into the code, making applications more robust and reducing the potential for human error.

5. Practical Applications#

  • Clinical Decision Support Systems (CDSS): Functions are the engines of CDSS tools. For example, a function can calculate a CHADS2-VASc score for stroke risk by taking patient characteristics (age, history of hypertension, etc.) as parameters. The programming technique of encapsulating this logic in a function allows it to be called reliably across the application. The real-world impact is that the function’s return value (the score) directly informs a clinician’s treatment plan, standardizing care and reducing cognitive load.

  • EHR Data Validation and Cleaning: Electronic Health Records (EHRs) often contain noisy or invalid data. In this medical context, a function like is_valid_bp(sbp, dbp) can be written to check if blood pressure readings are within a physiological range. This function, returning True or False, can be applied automatically during data entry or analysis to flag or clean erroneous records. The real-world impact is a dramatic improvement in data quality for both clinical research and direct patient care.

  • Pharmacokinetic (PK) Modeling: In drug development and personalized medicine, complex mathematical functions are used to model how a drug is absorbed, distributed, metabolized, and excreted. A Python function can implement this model, taking parameters like patient weight, age, and kidney function. The real-world impact is that the function’s return value—a prediction of the drug concentration in the blood over time—enables the creation of personalized dosing regimens that maximize efficacy and minimize toxicity.

6. Summary and Key Takeaways#

In this section, we’ve explored how to define and use functions in Python to create modular, reusable, and reliable code for clinical applications. We learned that functions are essential for abstracting away complexity and ensuring that calculations are performed consistently and safely across a software system.

The key takeaways from this section are:

  • Functions are defined with def and use return to output a result, making logic reusable.

  • Parameters act as placeholders for inputs, while arguments are the actual values passed to a function, allowing for dynamic computations.

  • Arguments can be passed by position or by keyword, and parameters can have default values to increase flexibility and code clarity.

  • Returning None is a standard and effective strategy for signaling a predictable failure (like invalid input) without causing a program crash, which is a critical safety pattern in medical software.

  • Good functions are documented with Google-style docstrings and use type hints for clarity and error prevention, which is vital for team collaboration and long-term maintenance.

You are now able to write functions that encapsulate clinical logic, accept patient data as inputs, and safely return calculated results. This is a foundational skill for building any robust health-tech application.
