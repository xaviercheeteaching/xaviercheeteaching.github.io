Chapter 2: Data Manipulation with Pandas#

1. Introduction: Finding the Patients Who Need You#

In precision health, your data is a sea of information. Your most critical task is to find the specific drops of data that matter—the patients who meet certain clinical criteria, the records that indicate risk, or the cohorts eligible for a new trial. This section is your guide to navigating that sea. You will learn the fundamental Pandas techniques for selecting and filtering data, moving from viewing entire datasets to precisely isolating the information you need. Mastering this skill is the first step toward transforming raw data into actionable clinical insights, allowing you to find the right patients at the right time.

2. Key Concepts and Definitions#

Understanding these core concepts is essential for effective data filtering in a clinical context.

  • DataFrame: A two-dimensional, labeled data structure in Pandas, much like a spreadsheet or a digital patient roster. Each column represents a variable (e.g., age, fasting_glucose_mg_dl), and each row represents an individual observation (e.g., a single patient record).

  • Series: A single column of a DataFrame. Think of it as a list of all values for one specific measurement, such as a list containing every patient’s glucose level. Selecting a single column from a DataFrame returns a Series.

  • Index: The label for each row in a DataFrame. While it defaults to a sequence of integers (0, 1, 2…), it can be set to a meaningful identifier like patient_id to allow for more intuitive, label-based data retrieval.

  • Boolean Masking: The core technique for conditional filtering. It involves creating a Series of True/False values based on a condition (e.g., patients_df['age'] > 65) and using this “mask” to select only the rows from the DataFrame where the value is True.

  • .loc[]: A primary Pandas method for selecting data by label. It is used for both selecting rows based on index labels (like patient_id) and for powerful conditional filtering (Boolean masking).

  • .iloc[]: A primary Pandas method for selecting data by its integer position. It is used when you need to retrieve rows or columns based on their numerical order (e.g., the first five patient records), regardless of their labels.

3. Main Content#

This section covers the primary methods for selecting and filtering data from a Pandas DataFrame. All examples will use the following sample patient dataset, which has been updated to reflect more realistic data formats.

import pandas as pd

# Sample patient data for a small clinic (assuming fasting glucose levels)
data = {'patient_id': ['PT000101', 'PT000102', 'PT000103', 'PT000104'],
        'age': [45, 68, 32, 71],
        'fasting_glucose_mg_dl': [95, 130, 88, 145],
        'diagnosis_code': ['Z00.00', 'E11.9', 'R03', 'E11.9']}
patients_df = pd.DataFrame(data)

Key Terms:

  • DataFrame: Think of this as a spreadsheet or a clinical database table, with rows representing individual patients and columns representing their data (e.g., age, diagnosis).

  • Series: A single column from a DataFrame. For example, selecting the age column gives you a Series containing all patient ages.

3.1 Selecting Columns#

Isolating specific variables, like vitals or diagnoses, is a common first step in any analysis.

# Select a single column (returns a Series)

print(glucose_levels)
# Output:
# 0     95
# 1    130
# 2     88
# 3    145
# Name: fasting_glucose_mg_dl, dtype: int64

# Select multiple columns (returns a DataFrame)
patient_vitals = patients_df[['age', 'diagnosis_code']]
print(patient_vitals)
# Output:
#    age diagnosis_code
# 0   45         Z00.00
# 1   68          E11.9

3.2 Selecting Rows by Position with .iloc#

Use .iloc[] to select data by its integer position, like pulling the first few patient charts from a physical stack.

# Select the first two patient records by their position
first_two_patients = patients_df.iloc[0:2] # Selects rows 0 and 1
print(first_two_patients)
# Output:
#   patient_id  age  fasting_glucose_mg_dl diagnosis_code
# 0   PT000101   45                     95         Z00.00
# 1   PT000102   68                    130          E11.9

3.3 Conditional Filtering with .loc#

While selecting by position is useful for exploring a dataset, most clinical questions require us to find patients who meet specific criteria. This is where conditional filtering with .loc becomes essential.

high_glucose_patients = patients_df.loc[patients_df['fasting_glucose_mg_dl'] >= 126]

3.4 Selecting Rows by Label with .loc#

To select rows by a meaningful label like patient_id instead of by position, you must first set that column as the DataFrame’s index.

# Create a new DataFrame with 'patient_id' as the index

print(patients_df_indexed)

3.5 Filtering with .query()#

The .query() method provides a more readable, string-based syntax for filtering, which can be especially useful for complex conditions.

# Re-run the compound filter using the .query() method
at_risk_query = patients_df.query('age > 65 and fasting_glucose_mg_dl >= 126')
print(at_risk_query)
# Output:
#   patient_id  age  fasting_glucose_mg_dl diagnosis_code
# 3   PT000104   71                    145          E11.9

3.6 Efficient and Safe Filtering#

Important: Avoid Chained Indexing to Prevent Errors Using .loc[rows, columns] is the gold standard. Chained indexing like df[condition][columns] can sometimes return a copy of the data instead of a view into the original DataFrame. If you try to change a value on this copy, the original patients_df will not be updated, leading to silent, hard-to-debug errors. This is known as the SettingWithCopyWarning.

Best Practice: Use .loc

# Correct: Single operation with .loc is explicit, efficient, and guaranteed to work.
correct_method = patients_df.loc[patients_df['fasting_glucose_mg_dl'] >= 126, ['age', 'diagnosis_code']]
print(correct_method)
# Output:
#    age diagnosis_code
# 1   68          E11.9
# 3   71          E11.9

Exercise 3: Priority Patient Flagging Intermediate#

Objective: Write a compound conditional filter to identify patients who meet one of two distinct risk criteria. Time: 5 minutes Medical Context: An automated alert system needs to flag patients for a priority check if they are either of an advanced age (over 70) OR have a potentially hypoglycemic glucose level (below 70 mg/dL).

Write a code snippet to identify all patients who are either over 70 years old OR have a glucose level below 70 mg/dL. Assign the result to a new DataFrame called priority_check_df, which should only show their age and fasting_glucose_mg_dl.

📝 Your Solution:

# TODO: Write your solution here
# Hint: Check the task description above
🔍 Click to reveal solution

Solution

# Define the two conditions and combine them with the OR operator `|`
# Select only the desired columns in the same .loc operation
priority_check_df = patients_df.loc[
    (patients_df['age'] > 70) | (patients_df['fasting_glucose_mg_dl'] < 70),
    ['age', 'fasting_glucose_mg_dl']
]
print(priority_check_df)
# Output:
#    age  fasting_glucose_mg_dl
# 3   71                    145

Explanation: This query is crucial for identifying two high-risk groups: elderly patients who may have complex comorbidities, and patients at risk of hypoglycemia (low blood sugar), which can be a medical emergency. We define two separate boolean conditions: (patients_df['age'] > 70) and (patients_df['fasting_glucose_mg_dl'] < 70). Each is wrapped in parentheses. They are combined with the | (OR) operator to find rows that satisfy at least one condition. In the same .loc call, we specify the columns ['age', 'fasting_glucose_mg_dl'] to return. Key Learning: Compound conditions with | (OR) or & (AND) must have each condition enclosed in parentheses. Selecting rows and columns simultaneously with .loc[rows, columns] is the most efficient method.

5. Practical Applications#

Data selection and filtering are foundational to nearly every task in computational precision health.

  • Clinical Trial Recruitment: Researchers use complex conditional filters to query large electronic health record (EHR) databases. They filter for patients who meet dozens of inclusion/exclusion criteria, such as a specific diagnosis (diagnosis_code.isin(['E11.9'])), an age range (age > 50 and age < 75), and the absence of comorbidities, to rapidly identify a viable cohort for a new therapy.

  • Automated Clinical Alerts: Hospital systems run scripts that filter real-time patient data every few minutes. Using .loc with compound conditions, these systems flag patients whose vitals cross critical thresholds (e.g., systolic_bp > 180 or oxygen_saturation < 90), triggering an immediate alert for the clinical care team and enabling rapid intervention.

  • Pharmacovigilance and Drug Safety: After a new drug is approved, analysts filter massive claims datasets to monitor for adverse events. They might select all patients prescribed a specific drug (drug_code == 'X') and then filter that cohort to see if there is a statistically significant increase in a particular diagnosis code, helping to identify previously unknown side effects.

  • Health Equity Analysis: Public health officials filter demographic and outcomes data to identify disparities. For example, they might use .query() to compare hospital readmission rates between different zip codes (zip_code.isin(['90210', '90211'])) for the same procedure, highlighting areas where targeted community health initiatives may be needed.

6. Summary and Key Takeaways#

In this section, we’ve explored the essential Pandas methods for isolating specific data within a DataFrame. You have learned how to select columns, retrieve rows by position with .iloc, and perform powerful conditional filtering using labels and boolean masks with .loc. We also covered the more readable .query() method and emphasized the importance of using .loc[rows, columns] for efficient and error-free selection.

  • Key Takeaways:

    • Select columns using df['col'] for a Series or df[['col1', 'col2']] for a DataFrame.

    • Use .iloc[] for position-based selection and .loc[] for label-based and condition-based selection.

    • Build complex filters by combining conditions with & (AND) and | (OR), ensuring each condition is wrapped in parentheses.

    • Always prefer the .loc[rows, columns] syntax over chained indexing ([][]) to avoid common errors and ensure efficiency.

With these filtering skills, you are now equipped to move beyond simply viewing data to asking targeted questions of it. In the next section, we will address the common challenge of messy data by learning techniques for cleaning and preparing it for analysis.
